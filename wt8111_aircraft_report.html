🎯 重大发现：飞机数据结构

飞机使用 type: "aircraft"，与坦克的 type: "ground_model" 不同。

{
  "type": "aircraft",
  "color": "#fa0C00",          // 敌军红色
  "color[]": [250, 12, 0],
  "blink": 0,
  "icon": "Fighter",           // 或 "Bomber"
  "icon_bg": "FighterTarget",  // 战斗机有此字段
  "x": 0.612049,               // 归一化 X (0~1)
  "y": 0.508955,               // 归一化 Y (0~1)
  "dx": 0.999254,              // 航向向量 X（归一化，模=1）
  "dy": -0.038620              // 航向向量 Y（归一化，模=1）
}
✅ 好消息：
  • 飞机有 dx/dy 航向向量，模严格等于 1.0，可以直接得到飞行方向
  • 飞机位置 x/y 实时更新，可以连续追踪
  • 能区分友军（蓝色）和敌军（红色）
  • 能区分轰炸机和战斗机（icon 字段）
❌ 坏消息：
  • 仍然没有高度字段 — 与坦克一样只有 2D 坐标
  • 所有字段：仅 ['blink', 'color', 'color[]', 'dx', 'dy', 'icon', 'icon_bg', 'type', 'x', 'y']
  • 没有速度字段 — 需要帧间差分估算
  • 没有高度 → 无法计算 3D 距离和弹道下坠

📐 dx/dy 航向向量验证

实测确认 dx/dy 是归一化方向向量（模 = 1.0），可直接换算为航向角：

快照dxdy模航向角说明
#00.99680.08011.00004.6°友军轰炸机，向东飞
#50.9993-0.03691.0000-2.1°微调航向
#100-0.44570.89521.0000116.5°敌军战斗机，向东北飞
#1080.8710.4911.000029.4°敌机转向东飞行
#1120.999-0.0331.0000-1.9°敌机已改为正东

公式：航向角 = atan2(dy, dx) × 180/π

这个向量比帧间差分更准确——它直接来自游戏引擎，无需估算！

🧮 对空提前量计算：可行性重新评估

更新结论：比之前预想的稍好，但仍然不够用。

✅ 能做到的

数据来源质量
敌机水平位置map_obj x/y✅ 实时，精度约 4m（0.001 归一化）
敌机航向map_obj dx/dy✅ 精确，归一化向量，模=1
敌机水平速度帧间差分⚠️ 约 ±10% 误差（1Hz 采样）

己方航向Player dx/dy✅ 有方向向量

❌ 做不到的

数据影响严重程度
敌机高度无法计算 3D 斜距、弹道下坠、炮弹飞行时间❌ 致命
敌机垂直速度俯冲/爬升时提前量方向错误❌ 严重
炮弹初速/弹道需从 Datamine 拆包获取⚠️ 可解决但麻烦
高采样率1Hz 下飞机移动 120m/帧，机动检测滞后⚠️ 严重

理论上的"勉强方案"

如果接受以下假设，可以做出一个非常粗糙的水平提前量指示器：

  1. 假设敌机高度 = 固定值（如 500m，典型 CAS 高度）
  2. 用 dx/dy 作为航向，帧间差分作为速度
  3. 水平距离从 x/y 计算
  4. 3D 距离 ≈ √(水平距离² + 假设高度²)
  5. 炮弹飞行时间 = 3D 距离 / 初速（从 Datamine 查）
  6. 提前点 = 当前位置 + 速度向量 × 飞行时间

但这只是水平面上的预测，不含仰角信息。你需要自己根据假设高度算出仰角，然后在屏幕上叠加。当敌机实际高度与假设不符时（俯冲/爬升），预测完全失效。

💡 最终建议

8111 数据可以用来做一个"半成品"对空辅助工具，但精度不足以用于实战瞄准。

有价值的用法

  • 敌机来袭警报 — 检测红色 aircraft 接近，播报"敌机方位XX度，距离XX米"
  • 小地图雷达 — HUD 上显示所有飞机位置、航向、类型
  • 威胁优先级排序 — 按距离和航向是否朝己方排序
  • 水平提前量参考线 — 在小地图上画出"如果敌机保持航速，N秒后在哪"

做不到的

  • 精确瞄准点 — 缺高度，无法算仰角和弹道下坠
  • 屏幕叠加瞄准 — 没有屏幕坐标映射，需额外截图标定

如果要更进一步

混合方案：8111 提供水平预测 + 截图估算仰角

  • 8111 算出敌机水平位置和速度 → 预测水平提前点
  • 截图识别敌机在屏幕中的垂直位置 → 估算仰角
  • 两者结合 → 得出 3D 瞄准点

复杂度高，但这是唯一能突破"无高度"限制的路线。
