⛏️ 二、数据挖掘 / 资源提取
gszabi99/War-Thunder-Datamine ⭐ 450Squirrel更新 2026-08
频繁更新的战争雷霆数据挖掘仓库（最热门 WT 项目之一）
  • 每次游戏更新后自动拆包并推送改动内容
  • 包含载具参数、武器数据、配置文件等完整游戏数据
  • 是众多其他工具的数据源（如 ThunderView、WTAPC 等）

klensy/wt-tools ⭐ 153Python更新 2023-05
战争雷霆资源提取工具集（也兼容 Cuisine Royale / Enlisted）
  • vromfs_unpacker — 解包游戏压缩归档 (.vromfs.bin)
  • dxp_unpack — 解包纹理归档 (.dxp.bin)
  • ddsx_unpack — 解包纹理文件 (.ddsx → .dds)，需 oo2core_6_win64.dll
  • blk_unpack — 解包 blk 数据文件为 JSON 或游戏原生格式
  • clog_unpack — 解密 .clog 日志文件
  • blk_minify — 压缩 blk 任务文件（突破 512KB 限制，适合 Modder）
  • 提供编译好的 exe 版本，无需 Python 环境
